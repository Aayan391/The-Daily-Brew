The Daily Brew ☕

A responsive, multi-page cafe website designed to provide a smooth and enjoyable browsing experience across desktop, tablet, and mobile devices.

🌐 Pages

Home — Hero section, popular menu items, why choose us, and testimonials.

Menu — Explore cafe food and beverages.

Gallery — Browse cafe and product images.

About — Learn about the cafe.

Contact — Find contact information and get in touch.

✨ Features

Responsive layout for different screen sizes.

Mobile navigation menu.

Reusable header and footer components.

Interactive elements using JavaScript.

Styled UI using Tailwind CSS.

Google Fonts and Font Awesome icons.

🛠️ Technologies Used

HTML5

CSS3

JavaScript

Tailwind CSS

Google Fonts

Font Awesome
